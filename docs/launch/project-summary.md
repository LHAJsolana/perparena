# PerpArena Project Summary

## One-Sentence Description

PerpArena is an independent simulated, risk-adjusted trading competition and analytics prototype that rewards consistency, risk management, and transparent scoring over raw account size or one lucky trade.

## 50-Word Description

PerpArena is a full-stack portfolio project for simulated perpetual-futures-style competitions. It generates deterministic synthetic participants and trades, calculates transparent analytics, ranks traders with a 0-100 risk-adjusted scoring model, surfaces explainable integrity heuristics, and presents public leaderboards, trader profiles, quests, and a safe demonstration admin center for technical evaluation and presentation.

## 150-Word Case-Study Summary

PerpArena explores a simple product thesis: trading competitions should reward skill, consistency, and risk management, not only account size, excessive leverage, artificial volume, or one lucky trade. The application is a Next.js, TypeScript, Prisma, PostgreSQL, Vitest, and Playwright portfolio project that simulates a seven-day perpetual-futures-style competition using deterministic synthetic data. The core engineering work separates raw trade normalization, analytics, scoring, integrity heuristics, engagement mechanics, data access, and UI rendering. The analytics engine calculates simulated P&L, ROI, drawdown, profit factor, leverage, daily returns, market allocation, and trade-frequency metrics. The scoring engine converts those metrics into a transparent 0-100 score, while the integrity engine surfaces reviewable simulation-based signals without claiming conclusive fraud detection. The project includes a public dashboard, leaderboard filters, trader profiles with charts, quests, achievements, guarded admin workflows, API boundaries, security hardening, and deployment documentation. It is not a real exchange and never executes trades. Built for public portfolio review.
